Developed a Mario-style platform game entirely in x86 Assembly where the player controls a character that must jump over obstacles to reach the end of the level. The game includes collision detection, obstacle management, jump mechanics, and a life system where the player has three lives before the game ends. Implementing these mechanics in assembly required building the game logic, movement control, and state management directly using processor registers, memory addresses, and low-level instructions without the abstractions provided by high-level languages. The project demonstrates strong understanding of low-level programming, real-time control flow, and efficient memory manipulation while creating an interactive game environment.
